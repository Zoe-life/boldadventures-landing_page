# Security Policy
# 
# If you discover a security vulnerability in our application,
# please report it to us responsibly by emailing security@boldadventures.com
# 
# Please include:
# - Description of the vulnerability
# - Steps to reproduce
# - Potential impact
# - Suggested fix (if any)
# 
# We will acknowledge receipt within 48 hours and work with you to
# resolve the issue promptly.
# 
# Do not publicly disclose the vulnerability until we have had a
# chance to address it.
